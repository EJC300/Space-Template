# Space Template
## About

There is this thing where people have made spaceship controls for other engines. I like to make space combat games. Others do too.  So that's where this comes in.

What this is *not* is a full game — not a full game or one with enemies, but it could be rewired for AI and Player schemes.

## Features

- Player Example of 6DOF Space Flight
- Support for health and shield/armor using a health resource
- Chase Camera
- Basic boosting
- Example player scene
- Basic sound

## What This Does Not Have

- Enemy or AI — that's for you to set up
- Event systems
- Origin shift
- Actual gameplay
