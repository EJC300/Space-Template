# Space Template
About: 	There is this thing where people have made spaceship controls for other engines but it usually costs money. I like to make space combat games. Others do too. But no good template exists for Godot. So that’s where this comes in. What this is not is a full game. Not a full game or with enemies but could be rewired for AI and Player Schemes.   	Features: 		Plug in and play SDOF spaceflight 		 		Support for health and shield or armor support using a health resource. 		  		Camera that can be setup for first person.  		Basic Boosting  		A fun super cruise thing sorry couldn’t resist.  		Example Player Scene.  		Basic Sound  	What this does not have:  		Enemy or AI thats for you to setup.  		Event Systems   		Origin Shift.
